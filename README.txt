Портфолио Ксении Груздовой — Контраст

Откройте index.html двойным щелчком. В этой папке находятся все файлы лендинга; для отдельного хостинга загрузите содержимое папки целиком.
Тексты кейсов и контакты: content.js. Основная страница: index.html. Оформление: style.css и cases.css.
Изменения в этой папке не затрагивают другой вариант. Внешние шрифты загружаются из Google Fonts; при отсутствии сети используются системные.
